# Swing Cool Kidz — Website

Static site for the Swing Cool Kidz (Đà Nẵng & Hội An swing dance community).

- **`index.html`** — English page (self-contained: styles + JS inline)
- **`vi.html`** — Vietnamese page (language toggle links the two)
- **`assets/`** — logos + Watch-card photos
- **`robots.txt`**, **`sitemap.xml`**, **`llms.txt`** — SEO / AI-crawler files
- No build step, no dependencies — just host the files.

Live: https://swingcoolkidz.netlify.app  (auto-deploys from GitHub `main`)

## Editing

Text lives in plain HTML. The two things you'll most likely touch:

1. **WhatsApp invite** — `WHATSAPP_INVITE` in the bottom `<script>`.
2. **Schedule** — dates are generated by an alternating-week rule:
   ```js
   const ANCHOR_MONDAY  = new Date(2026, 9, 5);   // first Blends week
   const SCHEDULE_UNTIL = new Date(2026, 11, 31); // how far ahead to generate
   ```
   Blends = Thursday, Hyatt = Wednesday, alternating each week. To extend into
   2027, bump `SCHEDULE_UNTIL` (and add occurrences to `calendar` if needed).

> Keep `index.html` and `vi.html` in sync — most copy edits need doing in both.

## SEO (search engines)
- Unique keyword-rich `<title>` / meta description per page ("swing dance / Lindy
  Hop in Đà Nẵng & Hội An, Vietnam").
- `rel=canonical`, `hreflang` (en / vi / x-default) on both pages.
- Open Graph + Twitter card tags (absolute `og:image`).
- **JSON-LD structured data**: `Organization`, `WebSite`, two `DanceEvent`s
  (Blends + Hyatt, with recurring schedule + price), and `FAQPage`.
- `sitemap.xml` + `robots.txt`.
- Visible **FAQ** section (mirrors the FAQPage schema).

### After deploy
Submit the site to Google Search Console and Bing Webmaster Tools:
`https://swingcoolkidz.netlify.app/sitemap.xml`

## AIO / AEO (being found by AI assistants)
- **`llms.txt`** at the root — a concise Markdown summary LLM crawlers can read.
- `robots.txt` explicitly allows GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, etc.
- FAQ + structured data give assistants clean, quotable answers.

## Traffic analytics (pick ONE, then enable)
The snippet placeholder is commented in the `<head>` of both pages.

- **A) Netlify Analytics** — dashboard → *Site configuration → Analytics* (paid add-on, zero code).
- **B) GoatCounter** (free, cookieless) — create a site at goatcounter.com, then add:
  ```html
  <script data-goatcounter="https://swingcoolkidz.goatcounter.com/count" async src="//gc.zgo.at/count.js"></script>
  ```
- **C) Cloudflare Web Analytics** (free) — paste the beacon script into the `<head>`.
